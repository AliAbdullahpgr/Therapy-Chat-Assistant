# **App Name**: Therapy Debate

## Core Features:

- AI Therapist Personas: Three distinct AI therapist personas with unique personalities: Dr. Chen (Evidence-Based), Dr. Williams (Holistic), and Dr. Rodriguez (Analytical).
- Debate Topics: Implement selectable mental health debate topics, with each debate lasting 5-7 minutes and including natural points for user intervention.
- User Chat Interface: Chat interface with visual distinctions for each AI persona, typing indicators, timestamps, smooth message animations, user input area, topic selector, and participant list.
- AI Response Tool: The AI 'responds' to the other AI speakers in the discussion and may include the user when reasoning about how the conversation proceeds. The LLM acts as a tool to determine when and how the conversation proceeds.
- Conversation Controls: Features to pause/resume conversation and control playback speed (normal, 1.5x, 2x).
- Transcript Export: Functionality to export complete transcripts in plain text, JSON, PDF, or Markdown format.

## Style Guidelines:

- Primary color: Light periwinkle (#D1D0CE) to convey calmness and a professional, trustworthy atmosphere.
- Background color: Very light periwinkle (#F5F4F2). Slightly desaturated for a subtle and calming effect.
- Accent color: Pale lavender (#D0C6E1) to add a gentle, contrasting highlight. This is a different value from the primary color in both brightness and saturation for optimal contrast.
- Headline font: 'Playfair', serif, to create a feeling of elegance, making a favorable first impression, while minimizing distractions in this application featuring user-generated content. Body text: 'PT Sans', sans-serif.
- Use professional and calming icons to represent each therapist persona and topic.
- Clean, organized layout with clear visual hierarchy for easy navigation and comprehension.
- Subtle animations for message appearance to create a smooth, natural conversation flow.
